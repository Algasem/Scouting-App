      7476 Scouting App - User Guide

      Match Scouting

      Before the Match (Fill this BEFORE scouting)

      • Event: Select the competition
      • Match Stage: Playoffs, Practice or Qualification
      • Driver Station: Check where the drivers are standing or check Blue Alliance
      • Match #: Current match number
      • Team #: Team you're scouting
      • Scout: Select your name from the dropdown

      Auto Tab

      • Climb Level: Did they climb in auto? (None or Level 1)
      • Alliance Auto Fuel Points: Total fuel-only points scored in autonomous by the alliance not including penalties
      • This Robot's Contribution: Use the slider to estimate what percentage of the alliance's auto fuel this robot scored. The Fuel Scored field will auto-calculate, but you can also type it in manually
      • Shot Accuracy: Use the slider to estimate accuracy. Fuel Missed will auto-calculate. You can also type missed shots in manually
      • Balls Collected: Check if they collected balls to their side

      Teleop Tab

      • Shots Scored / Shots Missed: Use the counter buttons (+1, +5, +10, +25) to track shots in real time during the match. These will carry over to Post Match automatically
      • Transition Phase Role: What the robot did during the transition phase (can select multiple)
      • Active Phase Role: What the robot did during the active phase (can select multiple)
      • Inactive Phase Role: What the robot did during the inactive phase (can select multiple)
      • Traversal: Bump, Trench, Both, or Didn't Move

      Endgame Tab

      • Climb Level: None, L1, L2, L3, or Failed
      • Climb Speed: N/A, Slow, Medium, or Fast
      • Disconnect: Did the robot disconnect? Yes or No
      • Notes: Important observations only: breakdowns, impressive plays, strategy notes. Concise is better. Only write things useful to the strategy team

      Post Match Tab (Fill this AFTER the match ends)

      • Alliance Total Fuel Points: Total fuel-only points scored in teleop by the alliance (shown in match stats after the match) — not including tower or penalties
      • This Robot's Contribution: Adjust the slider to reflect what percentage of the alliance's teleop fuel this robot scored. Fuel Scored syncs automatically from the Teleop counters but can be manually adjusted
      • Shot Accuracy / Fuel Missed: Adjust if needed based on final stats
      • Fouls: Count technical and regular fouls committed by the scouted robot
      • Collaboration, Driving Skill: Rate 1–4 (1 = poor, 4 = excellent teamwork)
      • Defence Rating: Rate 1–4 how effective their defence was
      • Defence Notes: Note any defensive plays worth flagging
      • Defence Rewatch Worthy: Mark Yes if there were outstanding or smart defensive plays the strategy team should rewatch

      After the Match

      1. Click Save Match button
      2. Match is saved to History tab. Also, a copy of the CSV will be saved to your device. We will have the option to disable this shortly.
      3. After 1 or several matches, go to the head scout and let them scan the QR code for each match. If you have internet connection, simply Sync to Spreadsheet and delete the match. You still need to tell the head scout you have scouted that match.
      4. After scanning or syncing, delete the match from history.
      5. Ensure the match has been synced or added before deleting, we do not want any progress lost!

      Pit Scouting

      • Switch to Pit tab at top
      • Fill out all fields:
      • Team Number: Team you're interviewing
      • Climb Level: Their max climb capability
      • Height/Weight: Robot dimensions
      • Intake Type: How they intake (can select multiple)
      • Drive Mechanism: Tank, Swerve, Mecanum, or Other
      • General Strategy: Ask them about their strategy (what do they do in a match)
      • Features: Vision tracking, adjustable scoring
      • Hopper Type: Fixed, Extendable (H/V), or None
      • Hopper Capacity: How many balls
      • Drive Experience: Rookie, Intermediate, Advanced, or Expert
      • Build Quality: Rate 1-10
      • Outside Perimeter: Does anything extend outside the frame perimeter?
      • Breakdowns: Any known issues or weaknesses
      • Notes: Additional observations

      History Tab

      Viewing Saved Data

      • Match History: Shows all saved matches as "Team# -- Match#"
      • Pit History: Shows all saved pits as "Pit Team#"
      • Click any entry to see QR code
      • Click ✏️ button to edit the data
      • If sync doesn't work, use QR or find Michael T or Algasem

      Editing Data

      • Click ✏️ next to any match/pit
      • Edit the CSV text directly (follow format!!!)
      • Click Save Changes
      • Or click Delete to remove match

      Troubleshooting

      "I saved but don't see it in History"

      • Refresh the History tab (switch away and back)
      • Check if the match count increased

      "Sync to Google Sheets failed"

      • Check internet connection
      • Make sure you're connected to WiFi or have data
      • Try again in 30 seconds
      • If it doesn't work find a strategy member and ask them

      "QR code won't scan"

      • Make sure screen brightness is at 100%
      • Hold scanner steady
      • Try zooming in on the QR code

      "I scouted the wrong team!"

      1. Go to History tab
      2. Click ✏️ next to the match
      3. Edit the team number in the CSV
      4. Save changes
